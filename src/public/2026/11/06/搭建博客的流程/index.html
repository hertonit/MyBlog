配置环境

该博客使用静态站点生成器 Hexo 和主题模板 Butterfly 构建，点击链接可进入官方文档。

注意: 在 Ubuntu 环境中下载 Hexo 必须要单独创建一个空文件夹

自定义主题

自定义主题可以用 Butterfly 模板, 如果要修改主题模板需要在 Hexo 根目录创建 _config.butterfly.yml 配置文件, 在里面外联 CSS 和JS 文件, CSS 和 JS 文件需要创建在 Hexo 根目录里的 source 文件夹里, 在 _config.butterfly.yml 配置文件中外联 CSS 和JS 文件的代码如下

在自定义主题的过程中有许多问题, 比如在 CSS 文件中的一些设置并没有生效, 这可能是由于定位优先级的问题, 解决方式就是将定位属性写得精确一些, 最好的解决方法是使用 AI 来修改
