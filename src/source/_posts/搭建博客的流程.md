## 配置环境

该博客使用静态站点生成器 [Hexo](https://hexo.io/zh-cn/docs/) 和主题模板 [Butterfly](https://butterfly.js.org/posts/21cfbf15/) 构建，点击链接可进入官方文档。
{% note 注意 %}
**注意: 在 `Ubuntu` 环境中下载 `Hexo` 必须要单独创建一个空文件夹**
{% endnote %}

## 自定义主题

自定义主题可以用 [Butterfly](https://butterfly.js.org/posts/21cfbf15/) 模板, 如果要修改主题模板需要在 `Hexo` 根目录创建 `_config.butterfly.yml` 配置文件, 在里面外联 `CSS` 和`JS` 文件, `CSS` 和 `JS` 文件需要创建在 `Hexo` 根目录里的 `source` 文件夹里, 在 `_config.butterfly.yml` 配置文件中外联 `CSS` 和`JS` 文件的代码如下

```yml
inject:
head:
    - '<link rel="stylesheet" href="/css/custom.css">'
bottom:
    - <script src="/js/custom.js"></script>
```

在自定义主题的过程中有许多问题, 比如在 `CSS` 文件中的一些设置并没有生效, 这可能是由于定位优先级的问题, 解决方式就是将定位属性写得精确一些, 最好的解决方法是使用 `AI` 来修改

## 部署网站

首先需要注册一个阿里云账号, 租一个云服务器, 这里服务器的操作系统使用 `Ubuntu` 操作系统

### 1.连接服务器
生成 `ssh` 密钥并连接服务器, 执行第一行的命令会生成两个文件, 文件后缀是 `.pub` 的是公钥, 另一个是私钥, 要连接阿里云服务器需要先在控制台里找到该服务器, 然后切换至标准模式, 找到网络与安全的密钥对, 创建一个密钥对, 之后执行下面的命令连接服务器

![](/img/搭建博客的流程1.png)

```
ssh-keygen -t ed25519 -f ./
ssh -i ./ecs_key 用户名@ip
```

### 2.将源代码上传服务器并运行

```
hexo clean
hexo g
scp -i ./ecs_key -r PATH 用户名@IP:PATH
```
